## Watch list (not top risks)
- **Windows Sticky Keys** interrupts play after five Shift presses. Mitigated and now a **Must**: Q/E and Z/X bindings all active at once (M1-16, tested in M1-27) and the one-time tip (logic and view in M1-40, mounted in M2-39). QA checks with a Windows user agent in M2-28 and M2-29. Owner: ui-engineer.
- **Control model churn.** The model changed once already (v1.0 auto-run to v1.1 hold-to-move). A second change after M1 would invalidate the level sketches, recordings and acceptance numbers. Mitigation: the control model is frozen at the M1 gate; any change after that is a user decision with a cost note from the producer. Owner: design-lead.
- **Determinism drift** from floating-point maths or hidden state would break the replay test and leaderboards. Guard rails: core-purity arch test (exists), M1-04, golden test M1-13. Each core sub-folder must be covered by the arch test (M1-41). Owner: tech-lead.
- **Windows line endings.** `core.autocrlf` is on for the user's machine; CRLF in level or solution files must not change parsing or replays. Mitigation: `.gitattributes` (M1-39), CRLF-tolerant parser and codec (M1-07, M1-43), a CRLF test. Owner: tech-lead.
- **Public flip is a single point of failure for jam eligibility.** The repo is private until `USER-6` on Nov 30. Mitigation: secrets audit (M4-09) before the flip, reminder at the M4 gate (Nov 28), S-02 verifies the repo in a logged-out browser. A Dec 1 buffer exists (jam closes 13:37 PST, 21:37 UTC). Owner: producer.
- **Four parallel gameplay-engineer sittings** share one working tree. Areas are disjoint by folder, but shared contracts live in `types.ts`; any contract change goes through tech-lead and a request. Owner: tech-lead.
- **Browser audio autoplay and iframe focus** on itch.io. Covered by M1-17, M1-24 and the embed check in M4-15. Owner: ui-engineer.
