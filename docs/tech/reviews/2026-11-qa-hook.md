## Decisions

- **Flag, not `?debug`.** The e2e suite runs against a production build, so the hook is a build-time switch that Playwright's `webServer.env` sets. Vite inlines both conditions, the minifier drops the branch, and CI greps `dist/` after the plain build.
- **`reuseExistingServer: false`.** A reused server on 4173 could be a plain (hookless) or stale build and fail every spec with "window.__redshift never appeared". Playwright now always builds and serves its own.
- **`workers: 2`** everywhere. QA measured 4 workers flaking on a loaded machine and 2 passing repeatedly; GitHub runners have 2-4 vCPUs, so CI loses nothing.
- **Viewport** moved into the chromium project after the `Desktop Chrome` spread (the preset's 1280x720 used to win).
